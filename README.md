# PC Browser Mac

Yupiteru PC Browserの録画用SDカード／IMGをMacで確認する、独立した読み取り専用GUIの試作です。
**v0.1.0 preview：Windows版の完全互換版ではありません。**

## できること

- 通常の`.img`ファイルを`O_RDONLY`で開く。
- `YP_FORMAT_1.01`の管理領域と、D101/D102の対になる映像パケットを範囲・長さ・複製ヘッダー照合付きで走査する。
- 録画LBA／チャンネル単位の一覧、カードの記録時刻、フレーム情報を表示する。
- Apple VideoToolboxでH.264をネイティブデコードし、再生・一時停止・フレーム送り・シークする。アプリの実行にFFmpegは不要。
- 接続状態の変更通知と、外部SDカードを選択して読み取り専用FDを受け取るヘルパーを備える。**実SD経路のエンドツーエンド動作は未検証**。

## 検証した範囲

macOS 15.7.7／Apple Siliconで、提供IMGの取得済み4MiBを使用しました。
99フレーム（2560×1080）をVideoToolboxでデコードし、GUI表示・20番フレームへのシーク・再生位置の前進を確認しました。単体テストは17件です。

**全31.5GBの実IMG検証が完了したことを意味しません。** テスト用の疎ファイルは、既知の2範囲だけを配置した部分フィクスチャーです。[検証記録](docs/validation.md)を参照してください。

## 現在の制限

- 初版は格納された映像をそのまま表示します。360°魚眼映像の展開・補正は未実装です。
- 音声、バイナリGPS／IMU、地図表示、正確なフレーム同期は解析中です。
- 再生速度の初期値30fpsは暫定です。0x1E8の値15を15fpsと解釈しません。画面で表示速度だけ変更できます。
- カード時刻のタイムゾーンは推測しません。
- 他機種、他形式、破損カード、循環記録の全パターンは未検証です。
- SDへの設定保存、消去、フォーマット、マウント／アンマウントは実装しません。

## ビルドと起動

ターゲットはmacOS 14以降。配布ZIPはApple Silicon（arm64）用です。Intel実機は未検証です。

```sh
swift test --jobs 2
./scripts/build-app.sh
open "build/PC Browser Mac.app"
```

Xcode Command Line Toolsが必要です。外部Swiftパッケージへの依存はありません。
生成される`.app`はアドホック署名で、Appleの公証は取得していません。

### IMG

「IMGを開く」から完全に取得済みのディスクイメージを選択します。全領域の走査はバックグラウンドで行われ、進捗表示とキャンセルが可能です。

### SDカード

「SDカードを選択」で外部の物理ディスクだけを列挙し、ユーザーが選択・管理者認証した場合のみ読み取り専用ヘルパーを起動します。内蔵ディスクやパーティション単体は対象にしません。
ヘルパーは常駐・setuid化せず、選択したディスクを`O_RDONLY`で開いたFDだけを渡して終了します。
アプリが書き込みをしないことと、macOSの通常マウントによる書き込みがないことは別です。原本保全が必要な解析ではイメージを使用してください。

## CLIによる検証

```sh
.build/debug/PCBrowserMac --inspect /path/to/card.img
.build/debug/PCBrowserMac --inspect /path/to/card.img --scan-limit 4193280 --decode-check --report /tmp/check.json
```

`--scan-limit`は最初の録画領域からの走査量です。上限付きの結果は必ず`partial_scan: true`と報告します。
`--decode-check`は選んだ範囲の各録画について、先頭で確認できたIフレームからVideoToolboxで検証します。

## 解析の出典とデータの扱い

Windows PC Browser 1.9.60.0をCraft Anything CLIの`--deep`で調べ、補助的なGhidra逆コンパイルと、提供IMGの読み取り専用観察で形式を照合しています。
[形式の観察記録](docs/format-observations.md)には確定事項と未解釈フィールドを分けて記載しています。

実際の録画、位置情報、設定値、IMG、検証用の映像・スクリーンショットはGitリポジトリへコミットしません。テストは合成データです。
