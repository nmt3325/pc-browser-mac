# v0.2拡張版の検証記録

全IMG取得、構造走査、映像デコード、GUI、実SD、出力ファイルは別々に記録する。原版全機能互換の達成を意味しない。実録画、GPSの実座標、機密設定、検証画像はこのリポジトリーに含めない。

## 完了済みの全IMG検証（korakuen）

- 全長31,486,640,128 bytes。全体SHA-256計算完了。
- 既知の先頭領域に加え、新たな5点の独立範囲取得と保存ファイルを照合。
- 439,666個のD101/D102対、993個の録画LBA／CHグループを確認。
- FFmpeg厳密デコードは180フレームの抜粋で成功。439,666フレーム全件のデコード成功を意味しない。
- 読み取り前後のサイズ／mtime不変。送信者側の全体ハッシュは未提供。

## Mac実機の追加メディア検証

macOS 15.7.7／Apple Silicon／Swift 6.2.4。実カードから取り出した1,200フレーム・3録画コンテナーを含む、55,456,256 bytesの**部分バックアップ**をSHA-256照合してMacへ転送。これは全31.5GBのMac側保持でも実物SDでもない。

## 途中で発生し修正した問題

- ピクセルバッファープールの取得失敗：明示的なCVPixelBuffer確保へ変更。
- 秒境界の同時刻フレームとepoch Doubleの丸め誤差により、MP4のPTSが重複してAVFoundation -11800／内部-16364で停止：整数秒の差分計算と最低1フレーム間隔で修正。書き出し時にも時刻の厳密増加を検証。
- 音声クロックで表示フレームを飛ばす際にGOPを毎回先頭からデコードする無駄を修正。前進ではデコーダーを再利用し、直近Iフレームより前への移動や大きなシークだけ初期化する。
- 初期の前方魚眼回転が逆向き：提供データの初期角を-90°に修正。機種別校正の完了を意味しない。
- 空き容量約186MiBで署名に失敗し接続も切断したが、容量確保後にビルド・署名・検証を再開。MP4の時刻不具合は容量とは独立に修正した。
