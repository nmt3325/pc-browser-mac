# 検証記録（preview）

## 成功した検証

- macOS 15.7.7、Apple Silicon、Swift 6.2.4でビルド。
- 合成データによる単体テスト17件：0失敗。
- 提供IMGの取得済み4MiBに含まれる99組の映像パケットについて、前後508 bytesの一致と入力範囲・長さを照合。
- Linux FFmpegを`-xerror -err_detect explode`付きで実行：99フレーム、標準エラー出力なし。
- macOS VideoToolbox：同じ99フレームを2560×1080でデコード。
- 実際のMacウィンドウを開き、プレビュー、20番フレームへのシーク、再生位置の前進を確認。Window Serverの合成済み画面もキャプチャーして確認。
- イメージのサイズと更新時刻が読み取り前後で不変。
- 取得済み範囲の転送SHA-256を確認。録画・画像・位置情報はリポジトリに含めない。

## 検証ではないもの

テスト用ファイルの論理サイズは原IMGに合わせていますが、配置されているのは既知のMBR範囲と4MiBの録画領域だけです。`partial_scan: true`として試験しました。
**全31.5GBのIMG、全録画、全機種を検証したという意味ではありません。**

SDヘルパーはコンパイル・パッケージ化済みですが、実SDカードを挿した状態での管理者認証、FD受信、全体走査のエンドツーエンド試験は未実施です。
音声・GPS・360°補正・正確なタイミングも未検証です。

機械可読な、実際の媒体情報を取り除いた結果は[validation.json](validation.json)を参照してください。
