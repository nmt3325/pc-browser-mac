# Windows PC Browser 1.9.60.0との機能差分

原版のメイン画面・メニュー全150項目・37アプリ用ダイアログ・Deep逆コンパイル・実IMG・Wine上の原版の実操作を照合した一覧です。メニュー項目ごとの状態は[棚卸し](menu-inventory.md)、ダイアログごとの対応は[個別マップ](dialog-port-map.md)、検証済み／未検証の区別は[未検証事項](validation-gaps.md)に記載します。表の「実装」は存在を表し、実機検証範囲とは区別します。**完成・完全互換を表しません。**

最新の公開版：v0.2.0-beta.3（build 16、コミット`2d4a62d0`）。コードはrun #146（コミット`5eea4d09`）で単体テスト408件・署名・ZIP展開後検査・GUI自己検査・梱包が成功し、公開された成果物そのものを実Mac（Apple Silicon、macOS 15.7.7）と実カードのイメージで検証済み（[検証記録](validation-full-port.md)の「Build 16」。一覧・履歴CSV・KML・MP4/AVI/印刷/PDF・BAK・削除/初期化・書き込み先満杯・イベント録画と常時録画#23/#11のGUI自己検査）。macOS 14での実行、Intel実機のGUI、物理SD、公証、4GiB超のAVI、原版とのピクセル比較は未検証です。その後に加えた映像抽出（build 17候補）はCI・実Macとも未確認です。
