# Windows PC Browser 1.9.60.0との機能差分

原版のメイン画面および59個のダイアログ資源、Deep逆コンパイル、実IMGを照合した一覧です。全37アプリ用ダイアログの対応は[個別マップ](dialog-port-map.md)、最新の検証範囲は[build 6検証](validation-full-port.md)に記載します。表の「実装」は存在を表し、実機検証範囲とは区別します。完成・完全互換を表しません。

|領域|Mac版の実装|差分・未確定事項|
|---|---|---|
|SD／IMG一覧|YP_FORMAT_1.01、D101/D102の検証、開始参照による連続録画一覧、ヘッダーのみの高速索引・選択時遅延照合・明示復旧走査、読み取り専用ヘルパー|実物SDのE2E、暗号化／他形式、全機種を未検証|
|動画操作|正逆再生、速度、コマ送り／戻し、シーク、秒数指定、音量／ミュート|逆再生・4倍速は消音。複数物理カメラ同時同期は未実装|
|360°表示|元魚眼、フラット、パノラマ、前後、4／16分割、ドーム、リング、全球、別ウインドウ|標準魚眼モデル。原版の全変換・工場校正・VR-pnとの厳密一致ではない|
|回転・NIGHT|yaw／pitch／roll、画角、露出、独自ガンマ、拡大|NIGHTは原版と同一の画素処理ではない|
|音声|記録形式を読み出してPCM再生・WAV保存、MP4にAAC・AVIにPCMで格納|他コーデック未対応。サンプル単位で工場同期との一致を未確認|
|GPS／地図|バイナリ座標、原版由来の測地変換、速度、MapKit、現在位置、経路、CSV/KML/GPX|原版Google Mapsとは別実装。外部NMEAはカードの明示タイムゾーン＋補正秒で同期可能。オプトインが必要。長いGPS欠落区間を補間しない|
|G／ジャイロ／入力|符号付きraw値、センサーグラフ、CSV、raw字幕・同一フレーム内のAND検索|物理G・角速度・軸方向・機種別校正未確定。外部入力表示の意味割当未確定|

|静止画|PNG／JPEG、IN/OUT、フレーム／秒間隔の連続PNG・マニフェスト|GUIの全間隔／取消／失敗パターンは未検証|
|動画保存|H.264 MP4、PCMからAAC音声、Motion JPEG/OpenDML AVI＋PCM、範囲、表示変換・選択字幕|AVIは独立デコード・音声一致・索引シーク確認。4GiB超の実映像は未検証。センサー／入力はraw字幕で意味割当なし|
|GPSログ|CSV、KML点／経路、GPX、KML色・透明度・幅・密度、明示選択時のみEarth起動|実際のEarthアプリ起動は未検証。原版の地図サービスとは別実装|
|バックアップ|選択録画を再生できるMac独自形式、原データ保持、SHA-256、原本には上書きしない|新しい通常IMGへの全入力コピー＋SHA-256読み戻しを追加。Windows BAK形式・物理SD復元ではない|
|印刷|1／4コマの改ページPDF、ネイティブ印刷、間隔指定|実データ9ページ／3ページを確認。物理プリンター・原版の全様式は未検証|

|設定変更|未実装|解像度・FPS・音声・画質・記録区画・上書き・衝撃／gyro・設置角度・電源／駐車・Wi-Fi・運転警告などのSD書き戻し|
|パスワード／消去／初期化|未実装|原版のパスワード入力・設定・解除、クイック／完全フォーマット、削除、機種指定初期化|

追加で週別録画待機時間、人物検知／警告／外部出力、接続ID／Wi-Fi設定なども原版に存在し、未対応としてTODOに残しています。

これらを未対応のまま「Windows版の全機能を備えた完全版」と表示・配布しません。
