# Windows PC Browser 1.9.60.0との機能差分

原版のメイン画面および59個のダイアログ資源、Deep逆コンパイル、実IMGを照合した一覧です。表の「実装」は存在を表し、実機検証範囲は別の検証記録に記載します。完成・完全互換を表しません。

|領域|Mac版の実装|差分・未確定事項|
|---|---|---|
|SD／IMG一覧|YP_FORMAT_1.01、D101/D102の検証、開始参照による連続録画一覧、ヘッダーのみの高速索引・選択時遅延照合・明示復旧走査、読み取り専用ヘルパー|実物SDのE2E、暗号化／他形式、全機種を未検証|
|動画操作|正逆再生、速度、コマ送り／戻し、シーク、秒数指定、音量／ミュート|逆再生・4倍速は消音。複数物理カメラ同時同期は未実装|
|360°表示|元魚眼、フラット、パノラマ、前後、4／16分割、ドーム、リング、全球、別ウインドウ|標準魚眼モデル。原版の全変換・工場校正・VR-pnとの厳密一致ではない|
|回転・NIGHT|yaw／pitch／roll、画角、露出、独自ガンマ、拡大|NIGHTは原版と同一の画素処理ではない|
|音声|記録形式を読み出してPCM再生・WAV保存、MP4にAACで格納|他コーデック未対応。サンプル単位で工場同期との一致を未確認|
|GPS／地図|バイナリ座標、原版由来の測地変換、速度、MapKit、現在位置、経路、CSV/KML/GPX|原版Google Mapsとは別実装。外部NMEAの映像自動同期なし|
|G／ジャイロ／入力|符号付きraw値、センサーグラフ、CSV|物理G・角速度・軸方向・機種別校正未確定。外部入力表示の意味割当未確定|
|検索・録画管理|日時／CH／ID、速度、GPS・音声有無、しおり、並び順、複数出力選択|GPS／音声／速度の未確認分は明示的な詳細検索で補完。原版のG／gyro条件、イベント／常時／履歴の意味別分類・トリガー検索未実装|
|静止画|PNG／JPEG、IN/OUT、連続PNG|連続出力の任意間隔設定は未実装|
|動画保存|H.264 MP4、PCMからAAC音声、範囲、表示変換・字幕|AVI／MotionJPEG、全インジケーター・センサー字幕未実装|
|GPSログ|CSV、KML経路、GPX、Google Earth等で開けるKML|点／線色・幅・密度等のGUIカスタム、Google Earthの直接起動未実装|
|バックアップ|選択録画を再生できるMac独自形式、原データ保持、SHA-256、原本には上書きしない|Windows PC Browser／PC Viewer形式、全カードの複製／復元ではない|
|印刷|現在の1コマ、範囲から4コマ|プリンター実機未検証、原版の全印刷様式は未再現|
|バージョン／設定閲覧|FAT16 CONFIG内のINI/TXT/CFG、機密値を隠す|モデル判定・ファームウェア更新・全設定の意味解析は未完|
|設定変更|未実装|解像度・FPS・音声・画質・記録区画・上書き・衝撃／gyro・設置角度・電源／駐車・Wi-Fi・運転警告などのSD書き戻し|
|パスワード／消去／初期化|未実装|原版のパスワード入力・設定・解除、クイック／完全フォーマット、削除、機種指定初期化|

これらを未対応のまま「Windows版の全機能を備えた完全版」と表示・配布しません。
