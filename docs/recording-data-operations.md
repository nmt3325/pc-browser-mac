# 録画データ削除・記録設定データ初期化

原版の「記録設定」ダイアログ（`録画データ削除`）にある2つの操作の保存形式と、この版（Mac）の扱いです。
原版を実行した結果（元データの変更を握りつぶして書き込み内容だけを記録）から読み取った事実だけを載せています。
カードやIMGの実データ、実際のセクター番号・世代番号・識別子はここにも、テストにも、リポジトリにも含めません（値はすべて合成例です）。

## 何が書き換わるか

どちらの操作も**録画データそのものは消去しません**。原版は管理セクター4つだけを書き込み、読み取り側がそれより古い録画を一覧に出さなくなることで「消えた」ように見せます。

| 書き込み順 | セクター | 内容 |
|---|---|---|
| 1 | 管理セクター | 世代番号・3つのカウンターを更新（初期化では設定も戻す）、チェックサム |
| 2 | チャンネル設定セクター | 削除では変更なし（書き込みは発生するが内容は同じ）。初期化では設定を戻す |
| 3 | バックアップのチャンネル設定セクター | チャンネル設定セクターと同じ内容 |
| 4 | バックアップの管理セクター | 管理セクターと同じ内容 |

録画データ領域への0埋めは行われません（書き込みは上の4セクターだけであることを、原版の書き込み記録で確認）。

## 世代番号とカウンター

管理セクターには次の値があります（詳細は [settings-format.md](settings-format.md)）。

| 場所 | 意味 |
|---|---|
| 0x00 と 0x1FF | カードの世代番号（1バイト。2か所は同じ値） |
| 0x1E0 | 常時録画のカウンター（4バイト、リトルエンディアン） |
| 0x1E4 | イベント記録のカウンター |
| 0x1E8 | 履歴記録のカウンター |

### 削除（「録画データ削除」）

- 世代番号は G → G′ = G + 1（255は上限として拒否）。
- 各カウンターは、**読み込まれていた領域の最新のリング周回世代 + 1** になります。
  - 常時・イベント：領域先頭のストリームヘッダーの世代（ダブルワード 0x1F8）。
  - 履歴：履歴ジャーナル先頭レコードの周回（ダブルワード 0xC4 の上位16ビット）。
- 領域に有効な録画が見つからなかった（読み込まれなかった）カウンターは、`max(元の値, G′)` になります（減らしません）。
- チェックサムは設定仕様の式（[settings-format.md](settings-format.md)）で再計算します。
- 設定（録画方法・時間・音声・Gセンサー・パスワード・カードID・領域表）は変わりません。

### 初期化（「記録設定データ初期化」）

削除と同じ世代番号・カウンターの更新に加えて、設定をダイアログの既定値に戻します。

| 項目 | 初期化後 |
|---|---|
| 録画方法 | 常時＋イベント |
| 録画コマ数 | 30コマ/秒 |
| イベント記録 | 録画前10秒＋録画後10秒 |
| 音声 | 録音する |
| 上書きフラグ（0x3A–0x3C） | すべて「上書きする」 |
| Gセンサー | あり・簡単設定・感度5 |
| ビープ音 | 鳴らす |
| 履歴記録 | 24時間・標準コマ数の標準レイアウト（領域表を標準式で作り直す） |
| パスワード | 解除（フラグ・語とも0） |
| マルチバッテリー | 1バイト目だけ0に戻す（2バイト目は触らない。例：(1,2)→(0,2)） |
| SDカードID | 変更なし |

領域表の履歴領域の終端は変えず、常時領域とイベント領域を標準式（`12 × floor(js × 71 / 1200)`、js はジャーナル開始セクター）で配置し直します。

## 操作ダイアログの文言

| 場面 | 文言 |
|---|---|
| 1回目の確認（削除、題名 記録設定、OK／キャンセル） | 録画データの削除を行います。\nよろしいですか？ |
| 1回目の確認（初期化） | 録画データの削除、\n記録設定データの初期化を行います。\nよろしいですか？ |
| 2回目の確認（初期化のみ、題名 録画データ削除、はい／いいえ） | 設定が変更されたため録画データが削除されます。続行しますか？ |
| 完了（削除） | 録画データの削除が完了しました。 |
| 完了（初期化） | 記録設定データの初期化が完了しました。 |

ダイアログのラジオボタンは「録画データ削除」と「記録設定データ初期化」の2つ、ボタンはOKとキャンセルです。

## 読み取り側の規則（どこまで分かっているか）

原版は、領域の先頭ヘッダーが**カードの現在の世代**に属し、かつその領域の周回世代がカウンターより大きいときだけ録画を一覧に出します。

- ストリームヘッダーの世代印（バイト 0xA0）がカードの世代番号（下位1バイト）と一致すること。
- 先頭ヘッダーの周回世代（ダブルワード 0x1F8）がその領域のカウンターより大きいこと。
- 履歴ジャーナルは世代印を持たないため、周回（ダブルワード 0xC4 の上位16ビット）がカウンターより大きいこと。

**この規則を原版で確認できたのは、カードの世代番号が1のとき（削除・初期化の前後）だけです。** 世代番号が2以上のカードでは、同じ操作の実験で原版が何も一覧に出さない結果になり、規則が1のときと同じとは言えません（領域表のエントリ検索の逆アセンブルでも説明できていません）。

そのためこの版は、**肯定的な証拠があるときだけ**録画を隠します。判定できないとき（検査可能な管理セクターがない、先頭ヘッダーが読めない等）は、これまでどおり表示します。
世代番号2以上のカードで隠れて見える／見えないが原版と一致するかは未確認です（[validation-gaps.md](validation-gaps.md)）。

## この版（Mac）の動作

- 原本のカード、マウント中のボリューム、読み込んだIMGには**書き込みません**。「記録設定」シートの「録画データ削除・初期化（新しいコピーへ）」と、コマンドラインの `--erase-recordings` は、新しいIMGコピー（APFSではクローン）を作り、コピーの4セクターだけを書き換えます（`WriteGuard`で新規ファイルのみ許可、ファイルモード0600）。
- 書き込み前に4セクターがコピー内でも読み取り時と同じことを確認し、書き込み後に読み戻して、4セクターの一致、設定の読み直し、世代番号・カウンターの一致、読み込まれていた領域が隠れていることを検証します。入力IMGの4セクターも変化していないことを確認します。
- 実行前に、原版と同じ文言の確認ダイアログを出します（初期化は2回）。
- 対応は録画チャンネル1つのカード（検査した形式、Q-01系）だけです。世代番号0または255、バックアップ管理セクターがない、チェックサムが合わない、チャンネル設定のバックアップが一致しない場合は拒否します。
- カタログ：`Catalog` は管理セクターを読み、領域を隠す判定の対象になった領域を一覧から除きます（`honorDeletion:`、既定は有効）。`ImageIndex.hiddenRegions` と画面の状態文、`--inspect` のJSON（`hidden_regions`）で、隠した領域と理由を確認できます。復旧スキャンは、削除済みの記録も含めて走査します。
- コマンドライン：

  ```
  --erase-recordings <image> --erase-kind delete|initialize --out <新しいimg> --confirm-erase \
      [--plan-only <json>] [--report <json>]
  ```

  `--plan-only` は何も書かず、世代番号・カウンターの前後、読み込まれた領域、変更点、4セクターのSHA-256などをJSONで出力します。

## 検証

- `Tests/PCBrowserCoreTests/RecordingGenerationTests.swift`：合成カードで、世代番号の判定、ヘッダーの世代印・周回世代・カウンターの規則、削除と初期化の計画値（カウンター・チェックサム）、コピーに書かれるのが4セクターだけであること、2回目の削除、拒否条件、バッテリーバイトの規則、操作文言、カタログ・ジャーナルの除外と`honorDeletion:false`・復旧スキャンを確認します。
- `scripts/settings_smoke.py`（CIの組み立てたアプリで実行）：実行ファイルの `--erase-recordings` で、合成IMGの削除コピー・もう一度の削除・初期化コピー・パスワード確認・保存し直しを、バイト単位の期待値と照合します。

### Macでの実カード画像（APFSのクローン）による確認

実カードの画像を `cp -c`（APFSクローン）で複製し、署名済みの成果物（Actions実行 #128）で削除と初期化を行い、31.5 GB全体を元の画像と比較しました。変わったのは、削除でちょうど2セクター（12バイト）、初期化でちょうど4セクター（54バイト）だけでした。クローンの目録は、削除後は録画0件・隠れた領域3、初期化後はイベント5件が見え、常時録画と履歴記録が隠れる状態でした。原本の画像は変更していません。

## 未確認・できないこと

- 実機のカードへの削除・初期化は試していません（原本には書き込まない方針のため）。
- 世代番号2以上での読み取り側の規則（上記）。
- 複数チャンネルのカード、Q-01系以外のダイアログクラス、機種指定初期化（フォーマット）、ファームウェア更新は解析していません。
